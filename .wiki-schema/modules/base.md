## 主题三大类（v4.0）

topics 顶层固定为三大类，编号控制排序：

| 大类 | 文件夹 | 内部结构 |
|------|--------|----------|
| **投资** | `02_投资/` | 宏观（02-10）→ 行业（02-20）→ 个券（挂在行业文件夹下）三层决策系统 |
| **旅游** | `03_旅游/` | 按目的地平铺（03-01 日本 / 03-02 瑞士 / 03-03 法国） |
| **个人** | `04_个人/` | 生活技巧（04-10）/ IT研究（04-20）/ 认知与成长（04-30） |

**投资层级（关键）**：个券不单独设枢纽，直接放进所属**行业文件夹**，形成「行业→个券」两级嵌套，可承载庞大标的池：
```
02-20_行业/02-2X_某行业/
├── 02-2X_某行业.md              行业档案
├── 02-2X-01_标的名_交易所代码.md  个券（如 02-21-01_中国卫星_SH600118.md）
└── 02-2X-02_标的名_交易所代码.md
```

## 页面命名规范

| 类型 | 路径 | 示例 |
|------|------|------|
| 实体页 | `wiki/entities/{名称}.md` | `wiki/entities/贵州茅台.md` |
| 主题-枢纽 | `wiki/topics/{大类}/{编号}_{名}.md` | `wiki/topics/02_投资/02_投资.md` |
| 主题-子页 | `wiki/topics/{大类}/{子文件夹}/{编号}-NN_{名}.md` | `wiki/topics/03_旅游/03-01_日本旅游.md` |
| 行业档案 | `.../02-20_行业/02-2X_{行业}/02-2X_{行业}.md` | `.../02-21_航空航天/02-21_航空航天.md` |
| 个券 | `.../02-2X_{行业}/02-2X-NN_{标的}[_代码].md` | `.../02-21_航空航天/02-21-01_中国卫星_SH600118.md` |
| 素材摘要 | `wiki/sources/{日期}-{短标题}.md` | `wiki/sources/2026-04-05-karpathy.md` |
| 对比分析 | `wiki/comparisons/{主题}.md` | `wiki/comparisons/自驾vs火车.md` |
| 综合分析 | `wiki/synthesis/{主题}.md` | `wiki/synthesis/AI工具生态.md` |
| 趣味发现 | `wiki/Interesting_findings/NN_第N期_{标题}.md` | `wiki/Interesting_findings/01_第一期_不请自来的关联.md` |

主题页编号规则：
- 文件夹内 `{编号}_{名}` 无连字符 = 该文件夹枢纽页
- `{编号}-NN_{名}` 一级连字符 = 子主题页
- `{编号}-NN-MM_{名}` 二级连字符 = 个券（行业下的标的）
- 编号前缀控制文件浏览器自然排序

## 交叉引用规范

- 页面间：`[[页面名]]`（Obsidian 兼容双向链接）
- 素材引用：`[来源: 标题](../sources/xxx.md)`
- 每个页面底部维护「相关页面」列表
- `[[wikilinks]]` 通过文件名匹配，与目录层级无关
