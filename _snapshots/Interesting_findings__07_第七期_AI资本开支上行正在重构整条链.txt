

# 第7期：AI 资本开支上行，正在把一条看似无关的链重构成同一条

> 本期把本周 23 篇素材里**最不显眼的那条暗线**拎出来：它们表面上分属机器人、存储、GPU、大模型、市场风格五个格子，但拆开看，全都是同一笔钱在不同环节的落点——**AI Capex 上行周期**。

## 一、现象：五篇素材，五个格子

| 素材 | 表面主题 | 看似无关 |
|------|----------|----------|
| 宇树科技 7 篇舆情 | 人形机器人 / IPO | 硬件制造，离"AI"较远 |
| Citrini 存储 / Global Memory Tech | 存储周期 | 周期品，和模型没关系 |
| AMD Helios / 天数智芯 | GPU / 算力 | 只看单一公司 |
| Kimi K3 / 智谱 | 国产大模型 | 纯软件层 |
| 180K 公众号 / 杠杆 K 型 | 市场叙事与资金 | 宏观情绪 |

把它们各自归档进 02-32 / 02-34 / 02-33 / 02-37，绝不会有人觉得它们是一伙的。

## 二、串联：一笔 AI Capex 的"下注—兑现—外溢"

真正的因果链是这样的：

1. **云厂商 + 国家算力规划**持续抬高 **AI Capex**（国泰海通《生根与重构》全景报告的核心判断）。
2. 这笔钱先砸向**算力硬件**：AMD 用 Helios 机架级系统正面挑战 NVDA，微软签约；天数智芯（9903.HK）乘中国 AI Capex upcycle 获"Buy + HK$1,000 目标价"。
3. 算力扩张立刻**外溢到存储**：Citrini 与 Global Memory Tech 两篇都指向 HBM/DRAM 的供需重构——没有足够的存储带宽，GPU 再多也喂不饱。
4. 同时**外溢到终端载体**：宇树科技的人形机器人是 AI 最性感的"物理落点"，IPO 注册生效意味着资本愿意为这条线买单。
5. 最后**反噬模型层**：Kimi K3 把竞争从"谁更聪明"拉到 **cost-per-intelligence（单位智能成本）**的定价权之争——模型层利润反而向硬件/云集中，智谱的估值波动只是这个过程的涟漪。

> 一句话：**AI Capex 是上游的水源，机器人/存储/GPU/模型是同一道水在不同梯田里的反光。**

## 三、弱关联彩蛋：资产荒下的"两类稀缺"

更隐蔽的一层：宇树科技（高确定性硬科技 IPO）和公募 REITs（类固收、Q2 环比边际改善）看似风马牛不相及，但放在"资产荒"框架下，它们其实是**同一类答案**——在确定性溢价稀缺的环境里，市场愿意为"能算清楚现金流/成长"的标的支付溢价。这也解释了为什么 180K 说的"AI 叙事切换"和杠杆资金 K 型分化能共存：钱没走，只是从"叙事溢价"换到了"基本面溢价"。

## 四、可执行的追踪清单

- **上游水位**：AMD Helios 交付节奏、天数智芯 IPO 定价、北美云厂 Capex 指引。
- **外溢验证**：存储（Citrini/Global Memory）的量价信号是否兑现为板块行情。
- **终端兑现**：宇树上市后定价 vs 一级市场估值；具身智能订单是否从"饥渴"变"交付"。
- **反噬信号**：Kimi K3 之后，模型层是否出现更多"按智能计费"的定价模式。
