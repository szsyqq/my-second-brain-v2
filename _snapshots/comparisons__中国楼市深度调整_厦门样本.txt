

# 对比：中国楼市深度调整——厦门样本

> 基于石榴叔（16号内参）对厦门楼市的独家分析

## 厦门楼市特殊定位

厦门房价定价逻辑特殊，叠加了：岛内稀缺 + 学区溢价 + 改善预期 + 民间财富 + 资产避险 + "厦门房子不会差"的长期信仰。

## 当前状态：深度调整中后期

| 维度 | 表现 |
|------|------|
| 岛内 | 同板块价差悬殊，次新房 vs 老小区差距拉大 |
| 岛外 | 降价更明显，翔安出现单价不足万元商品房 |
| 新盘 | 高端盘继续冲高（五缘湾陆拾岛 18.7 万/平刷新纪录） |
| 刚需 | 低总价小户型走量最快 |
| 僵持 | 卖家不愿再降，买家不愿接盘 |
| 学区 | 核心学区房坚挺，但老破大有学区弱化风险 |

## 定价逻辑变化

- **地价**决定房价上限
- **产品力**决定房价下限
- **房龄**成为越来越重的负向系数
- **产品迭代快**：保鲜期缩短，买错房子代价更高

## 新购买力结构

- 科技造富（杭州、深圳、合肥）创造新购买力
- 买家变年轻：80后、90后进入高端市场
- 不再为老牌豪宅、老学区、老地段的历史溢价买单
- 在意产品、审美、圈层、会所、物业

## 风险信号

- 中产改善计划取消/推迟
- 收入下滑、工作不稳定
- 下半年金九银十不乐观
