

# 055型驱逐舰

> 中国人民解放军海军的万吨级大型导弹驱逐舰（北约代号：Renhai-class / 刃海级），代表中国海军从「黄水」近海走向「蓝水」远洋的关键装备节点。

## 简介

055型驱逐舰是中国海军现役排水量最大的驱逐舰级别，属于信息化、隐身化的万吨级导弹驱逐舰。其定位为航母编队与远洋特混编队的核心护航力量，主要承担区域防空、反导、反舰、对陆攻击与反潜等综合作战任务。该级舰被认为是中国海军迈向「蓝水」远洋海军的标志性装备之一——从近海防御的「黄水」走向全球存在的「蓝水」。

## 关键特征（公开资料）

| 维度 | 概况 |
|------|------|
| 舰级定位 | 万吨级大型驱逐舰 / 驱逐舰领舰（DDG） |
| 排水量 | 约 12,000–13,000 吨级（公开估算） |
| 首舰 | 南昌舰（101），2020 年前后入列 |
| 舰体设计 | 一体化桅杆、隐身外形、长艏楼设计 |
| 垂发系统 | 大口径通用垂直发射单元（VLS），数量约 100 单元以上 |
| 作战能力 | 区域防空、反导、反舰、对陆打击、反潜 |

## 作战定位

- **航母编队「带刀护卫」**：为航母（如福建号航母等）提供远程区域防空与反导屏障。
- **远洋特混编队指挥节点**：较大的舰体与信息化能力使其可作为编队指挥平台。
- **多任务均衡**：相比专职防空或反潜舰，055 在防空、反舰、对陆、反潜上更为均衡，是综合战力平台。

## 同型与关联

- 同级别后续舰（如南宁舰等）陆续入列，构成批次化建造与部署。
- 与航空母舰、综合补给舰等组成远洋编队，是中国海军远海训练与护航的常客。
- 在军事科普语境中，055 常与 「从黄水走向蓝水」 的海军转型叙事绑定，被视为装备现代化的象征。
