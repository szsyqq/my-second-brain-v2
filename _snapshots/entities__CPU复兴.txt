

# CPU 复兴（CPU Renaissance）

> Agentic AI 推动的服务器 CPU 需求扩张主题：数据中心架构从"GPU 中心"转向"CPU 密集"，CPU:GPU 比从 1:8 走向 1:1，全球服务器 CPU 市场（TAM）五年内扩张近 6 倍。

## 简介
"CPU 复兴"（CPU Renaissance）由 Bernstein 在 2026 年提出，指 Agentic AI（智能体 AI）的兴起使数据中心计算从 GPU-centric 重新变为 CPU-intensive——因为智能体推理需要大量通用 CPU 编排与并发。这逆转了此前"AI = GPU"的单一叙事：GPU 负责大规模并行训练/推理，但每一个 GPU 集群都需要 CPU 来调度、预处理、编排任务与管理 I/O，智能体时代这类"非张量"工作负载显著膨胀。

## 定义与机制
- **角色分工**：GPU 擅长高吞吐并行矩阵运算；CPU 擅长通用控制流、分支逻辑、系统编排与低延迟服务。Agentic AI 中大量"规划—调用—校验"的串行/分支任务落在 CPU。
- **配比变化**：随着推理与智能体负载提升，单 GPU 对应的 CPU 算力和核数需求上升，推动 CPU:GPU 配比从约 1:8 收敛到约 1:1（Bernstein 预测）。

## 关键信息
- **TAM 扩张**：全球服务器 CPU 市场 $39bn（2025）→ $223bn（2030，Bernstein 预测）
- **CPU:GPU 比**：1:8（当前）→ 1:1（2030）
- **中国 x86 服务器 CPU TAM**：$7bn（2025）→ $27bn（2030）
- **受益方**：国产 x86 龙头 [[海光信息(Hygon)]]、全球 CPU 厂；节奏上 2028 起加速（产能 + AIDC）

## 核心特性
1. **范式位移**：不是 GPU 被替代，而是 CPU 需求被 Agentic AI 显著抬升，与 [[NVIDIA]] 的 GPU 叙事互补而非对立。
2. **国产替代窗口**：海外 CPU 产能优先供美国云厂，对华供应不确定，催化国产 CPU 认证（AI 芯片的翻版）。
3. **投资含义**：CPU 链（x86 国产、服务器、相关生态）迎来比市场当前认知更大的机会。

## 风险与边界
- **预测属性**：TAM 与配比均为 Bernstein 预测，依赖 AI 资本开支持续与智能体落地节奏，存在下修风险。
- **周期属性**：服务器与半导体具强周期，若 AI 开支放缓，扩张逻辑会反向。
- **技术替代**：ARM/云厂自研架构可能改变 x86 份额格局，需持续跟踪。
