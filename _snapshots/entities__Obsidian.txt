

# Obsidian

> 基于本地 Markdown 文件的双向链接笔记工具，支持知识图谱可视化，是构建个人知识库 / 第二大脑的主流前端。

## 简介

Obsidian 是一款以本地 Markdown 文件为核心的笔记应用。其最大特色是**双向链接**（用 `[[页面名]]` 语法），可自动生成可视化的知识图谱，非常适合实践「卡片盒」「第二大脑」等知识管理方法。所有笔记就是本地 `.md` 文件，不锁定在私有数据库，可用任何编辑器打开，与 AI 工具（Codex、Claude 等）直接读写本地文件的能力天然契合。

## 核心特性

| 特性 | 说明 | 知识库价值 |
|------|------|-----------|
| 本地优先 | 笔记即本地 MD 文件 | 数据自有、可版本管理、可被 Agent 直接读写 |
| 双向链接 | `[[页面名]]` 互相引用 | 形成可导航的知识网络 |
| 图谱视图 | 可视化页面关联 | 发现孤立页面与知识盲区 |
| 插件生态 | 社区插件扩展能力 | 如 multi-source-sync、Dataview 等 |
| 即时渲染 | 编辑与预览一体化 | 写作流畅 |

## 在本知识库中的用法

- 打开文件夹即 vault，`raw/`（原始资料）与 `wiki/`（编译知识）分层是关键。
- 配合 Codex / Agent 等 AI 工具，让 Agent 直接读写本地知识库文件，完成 ingest 与 Lint。
- 用 multi-source-sync 类插件把小红书等平台收藏同步进 `raw/inbox/`，再经 `/gx` 消化。
- 知识图谱视图可快速定位孤立页面与待补强的概念。

## 使用原则

- 不必一开始装很多插件，先保持干净跑通「收集 → 消化 → 查询」最小闭环。
- `raw/` 与 `wiki/` 分层是底线，不可妥协，否则 AI 难以稳定读写。
- 建议先建独立实验仓跑通闭环，再用到主仓库，避免复杂配置干扰。
