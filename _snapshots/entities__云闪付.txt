

# 云闪付

> 中国银联推出的移动支付应用，支持付款码、扫码支付、银行卡管理等，是内地主流移动支付工具之一，也是香港信用卡在内地消费获取高返现的关键渠道。

## 简介

云闪付（UnionPay QuickPass）是中国银联旗下的移动支付平台。用户绑定银联卡后，可通过「付款码被扫」或「主动扫码」完成支付。与微信支付、支付宝不同，云闪付基于银联网络结算，对商户类别码（MCC）的识别更准确，因此在香港信用卡（如 HSBC Pulse）的返现活动中扮演关键角色——能否正确识别餐饮等分类，直接决定返现比例。

## 核心功能

| 功能 | 说明 |
|------|------|
| 付款码 | 出示二维码给商户扫描（被扫模式） |
| 扫一扫 | 主动扫描商户收款码（主扫模式） |
| 银行卡管理 | 绑定 / 管理多张银联卡 |
| Rewards+ | 汇丰 App 内置的银联付款码功能（与云闪付同源） |
| 转账 / 便民 | 信用卡还款、水电煤缴费等便民服务 |

## 在跨境消费返现中的优势

- **商户识别准确**：通过银联网络直接结算，商户 MCC 正确传递，可触发餐饮等特殊类别返现。
- **与微信 / 支付宝的核心区别**：微信 / 支付宝「跳转云闪付」时，商户显示为 Tencent / Alipay 而非实际商户，导致餐饮 5% 等分类返现失效。
- **支持 POS 机**：多数线下 POS 机同时支持银联闪付（含云闪付），即便收银口头称「不支持」，改用刷卡通常仍可走云闪付通道。

## 使用建议

- 在内地消费优先直接用云闪付付款码 / 扫码，而非经微信、支付宝跳转。
- 配合 Apple Pay 使用时，确认扣款卡为银联双币卡（如 HSBC Pulse）以叠加返现。
- 美团等平台用「美团买单 + Apple Pay」组合可叠加团购优惠。

## 注意事项

- 云闪付的返现收益来自所绑定银行卡的活动，本身不额外发券；高阶用法是把它作为「正确识别商户」的支付通道。
- 部分小微商户仅支持微信 / 支付宝聚合码，此时可尝试用云闪付扫其银联收款码。

## 不同素材中的观点

- **小红书 · Pulse 实战攻略**：云闪付付款码与扫码是 HSBC Pulse 卡的 A 类支付方式，可拿满全部返现活动（2% + 5% + Guru）。关键区别在于直接使用云闪付（商户正确识别） versus 通过微信 / 支付宝跳转（识别为 Tencent / Alipay，分类返现丢失）。（来源：[[2026-07-11-HSBCHKpulse内地澳门MO实战]]）
