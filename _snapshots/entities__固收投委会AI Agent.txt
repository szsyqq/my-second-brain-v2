

# 固收投委会 AI Agent

> 华泰研究张继强团队实践的"类投委会"多角色 AI 智能体框架：用 13 个角色 + 多轮辩论，把固收投资决策变成"过程+结论"可审计的系统。

## 简介
固收投委会 AI Agent 是华泰研究（2026-07-05 利率周报）披露的 AI 应用实践。它不追求"AI 直出结论"，而是搭建一个模拟真实投委会的多角色研讨框架，让多个 AI 角色在受研究框架约束的前提下独立判断、互相质询，最终由"投资总监"综合。

## 关键信息
- **角色（13 个）**：宏观、政策、机构行为观察员、PM×5、风控与交易员×2、投行与监管观察员×2、投资总监
- **流程**：数据收集 → 宏观政策陈述 → 机构行为分析 → 风控质询 → 五PM三轮辩论 → 投行/监管补充 → 投资总监综合（不投票、负最终责任）
- **两种模式**：纯文本模式（日常跟踪）；子 Agent 模式（季度策略/重大仓位/对立观点裁决）
- **人为控制点**：继续/停止/深入/跳过/引入新角色，等待用户输入才进下一轮

## 核心特性
1. **可审计**：输出过程+结论，决策可追责、新人可学——解决"AI 黑箱不可信"。
2. **抗群体思维**：子 Agent 让每个 PM 在独立上下文中强制独立判断，避免单一上下文累积。
3. **启发式**：互相质询的尖锐问题、裂缝深挖的归因，不乏高质量研究讨论。
4. **受限**：辩论质量受制于数据精度（债基久期、理财规模、分机构日频数据尚不能经 MCP 调取）；存在幻觉；需外部知识库对接 + 事实核查。
