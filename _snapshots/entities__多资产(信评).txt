

# 多资产(信评)

> 在信用评级（信评）从业语境下，「多资产」特指需要信用分析能力、但定价逻辑与风险收益特征与普通信用债有明显差异的资产类别，是信评从业者能力拓展的主要方向。

## 简介

多资产研究是信评行业近年来的重要趋势。随着传统信用债市场成熟化与收益率下行，越来越多信评从业者开始拓展能力边界，涉足含权信用债、可转债、REITs、ABS 等「需要信用分析功底、但分析框架不同」的资产类别。其核心认知是：信评的核心能力（偿债意愿与能力判断、现金流分析、条款解读）可以迁移，但每类资产的定价逻辑与风险点差异显著，需要重新建立框架。

## 涵盖资产类别

| 类别 | 信用分析要点 | 定价特点 |
|------|------------|----------|
| 含权信用债 | 回售 / 赎回 / 票面调整条款分析 | 条款价值嵌入定价 |
| 二永债（二级资本债 / 永续债） | 银行信用 + 次级条款 + 减记 / 转股风险 | 信用利差 + 条款补偿 |
| 可转债 / 可交债 | 发行人信用 + 转股条款 + 下修博弈 | 股债双重属性 |
| 公募 REITs | 底层资产质量 + 运营能力 + 分红可持续性 | 类股权定价 |
| ABS / MBS / 类 REITs | 资产池质量 + 现金流分析 + 增信措施 | 结构化分层定价 |
| 机构间 REITs | 同上 + 流动性差异 | 折溢价复杂 |

## 信评转型多资产的核心方法论

### 三维度研究体系

1. **深度学习（输入）**：每日保持大量研报输入，问题导向阅读，利用 Wind / 慧博 / DM 等免费或机构渠道。
2. **总结思考（输出）**：框架化、体系化笔记——如「上下中游行业」框架连接宏观—中观—微观。
3. **同业交流**：保持与同行切磋，获取不同视角，校正自己的分析盲点。

### 可转债入门路径

- 精研 10 份以上不同信用资质公司的募集说明书。
- 深入理解下修 / 回售 / 赎回条款与触发机制。
- 建立「回售价与正股价逼近时，下修概率的压力测试」分析逻辑。
- 输出深度专题报告，将碎片化认知沉淀为可复用的框架。

## 职业启示

买方信评的最终锚点是投资端需求——多资产能力让信评从「评级支持」走向「投资研究支持」，价值边界显著拓宽。对从业者而言，转型的关键不是抛弃信用功底，而是把它作为迁移基座，逐个攻克新资产类别的分析框架。

## 不同素材中的观点

- **公众号 · 信评百万**：多资产转型是信评行业的必然趋势，买方信评的最终锚点是投资端需求。可转债是信评切入多资产最自然的入口，条款分析是信评的核心能力；精研募集说明书可建立「从信用视角看转债」的分析框架。（来源：[[2026-07-12-信评如何培养多资产能力]]）
