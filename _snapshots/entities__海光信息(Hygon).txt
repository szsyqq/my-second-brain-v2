

# 海光信息（Hygon）

> 国产 x86 服务器 CPU 龙头（688041.SH），国内唯一可替代 Intel/AMD 的 x86 服务器 CPU 供应商；在 Agentic AI 驱动的"CPU 复兴"中，凭国产替代与 TAM 扩张双重逻辑被 Bernstein 列为 Outperform（目标价 ¥450）。

## 简介
海光信息从事高端处理器（CPU/DCU）研发销售，其 x86 服务器 CPU 源自 AMD 授权并独立演进（2019 年被列入 Entity List 后无法获取 AMD 进一步技术支持，但维持 2-3 年技术差距）。凭借"唯一国产 x86"卡位，成为信创与国产替代的核心标的，并布局 CPU+AI 芯片生态捆绑。

## 关键信息
- **代码/市场**：688041.SH（科创板）
- **独占位**：国内唯一可替代 Intel/AMD 的 x86 服务器 CPU 厂
- **份额**：中国 x86 服务器 CPU 市场价值份额 19%（2025）→ 36%（2030，Bernstein 预测）
- **技术**：较全球 x86 龙头落后 2-3 年，但覆盖约半数中国市场；C86-G5 将显著升级
- **节奏**：2025-28 受供给约束，2028 起随国内产能 + AIDC 投资加速再加速

## 核心特性
1. **国产替代刚需**：海外 CPU 产能优先供美国云厂，对华供应不确定性上升，CSP 认证国产替代动力强（AI 芯片先例）。
2. **CPU 复兴受益**：[[CPU复兴]] 使服务器 CPU TAM 从 $39bn（2025）扩至 $223bn（2030），海光直接受益。
3. **生态捆绑**：CPU + AI 芯片可打包销售，提升两芯片出货量。
4. **估值锚**：Bernstein Outperform、PT ¥450（2026-07）。
