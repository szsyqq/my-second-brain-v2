

# 智方便申请香港国际驾照IDP｜内地住址证明ok

> 用香港「智方便」App 网申国际驾驶许可证（IDP），经香港交通署邮件确认内地银行账单可作为住址证明，全程约 14 个工作日，费用 HKD80。凭 IDP + 中国护照可在济州岛租车。

## 核心观点

1. **内地住址证明经交通署确认可用**：香港交通署官网未明确写内地住址证明是否可用，作者发邮件确认后获得肯定答复，并成功办理，证明此路径可行
2. **IDP 是济州岛自驾的唯一通行证**：济州岛仅认可 IDP 或在韩国考本地驾照，IAA、IDD、翻译件等均不被接受；IDP + 中国护照可在济州岛租车
3. **全线上流程约 14 个工作日**：智方便 App 手机操作 → 缴费 HKD80 → 电邮补充材料 → 批准 → 邮寄上门，全程无需线下跑腿
4. **住址证明来源**：打电话给银行信用卡中心，邮寄带地址抬头的纸质账单（作者使用建行，约一周收到）
5. **淘宝代递可选但建议自办**：中介收费 300-500 元，主要是不放心证件原件交给别人

## 实操内容保留

### 申请条件（缺一不可）

1. 香港身份证
2. 香港驾照（无香港驾照需先办理）
3. 白底照片（电子版）
4. 3 个月内住址证明（内地银行纸质账单可用）

### 时间线参考

| 日期 | 事项 |
|------|------|
| 7月17日 | 智方便 App 提交申请，缴费 HKD80，当天收到确认电邮 |
| 7月26日 | 收到补充材料电邮（原香港地址未删除导致确认），可通过智方便或电邮回复 |
| 7月29日 | 电邮通知申请已批准，准备邮寄 IDP |
| 8月1日 | 收到派送编号电邮，可查进度 |
| 8月5日 | 快递员上门派件，收到 IDP |

### 关键注意事项

- 非香港身份不能办 IDP
- 办理前需确认智方便 App 已升级签署功能
- 内地住址证明建议用银行信用卡纸质账单（约一周邮寄）
