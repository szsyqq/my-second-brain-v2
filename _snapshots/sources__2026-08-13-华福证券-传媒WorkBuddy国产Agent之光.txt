

# 传媒行业：WorkBuddy，国产 Agent 之光

> 华福证券 / 2026-08-23 / 传媒&AI 应用 / [本地PDF](raw/inbox/pdfs/华福证券-传媒行业：WorkBuddy，国产Agent之光-20260423-.pdf)

## 核心观点

1. **WorkBuddy 作为国产 AI Agent 标杆**：从 ChatBot 走向「能调用工具、能执行任务」的 Agent，代表中国 AI 应用层的突破。
2. **产业意义**：Agent 把大模型能力产品化，打开企业级与工作流场景的付费空间；利好国内 [[AI Agent]] 生态与算力需求。
3. **投资映射**：关注 Agent 平台、AI 应用（传媒/办公/客服）、以及底层 [[国产算力自主]] 的二次拉动。
4. **与腾讯的协同**：[[02-33-10_腾讯控股_0700HK]] 等巨头若将 Agent 嵌入超级 App，存在流量与商业化重估。

## 关键概念

- [[WorkBuddy]]: 国产 Agent 代表产品，从对话到执行的跃迁。
- [[AI Agent]]: 大模型落地的关键形态，工具调用+任务规划。
- [[国产算力自主]]: Agent 普及反哺本土算力需求。
