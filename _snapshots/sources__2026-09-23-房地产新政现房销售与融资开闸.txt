

# 房地产新政解读：现房销售与资本市场支持

> 来源：凤凰网财经｜发布 2026-09-08（文内述 8 月 28 日政策落地）｜嘉宾：刘戈 / [[付鹏]] / 席迎春

## 核心观点

1. **两份政策同日落地（2026-08-28）**：住建部等三部门联合推进商品住房[[现房销售]]；证监会同步发布资本市场支持房地产发展新模式一揽子举措。配套：最长贷款期限 **30 年 → 40 年**、预售项目房贷严格在竣工备案后发放、收入偿债比例上限上调。
2. **刘戈：期房的低价本质是"风险定价"**。资金充沛、开发能力强的房企更愿卖现房（看得见、可卖高价）；坚持以期房预售，往往暴露自有资金不足 / 融资短板。期房低价 = 一笔"风险费"——"烂尾不是概率游戏，而是 0 和 100% 的区别"。
3. **付鹏：刚需买房的首要属性是居住，别纠结升值**。中年"中登"群体第一步是**降杠杆、还房贷、保现金流**，而非投资；楼市已从城镇化 / 人口红利驱动的"扩圈时代"进入 **[[缩圈时代]]**，房产投资逻辑转向一线核心地段的稀缺新房（价格高、不适合普通刚需）。
4. **席迎春：融资"开闸"不是救市，是重建行业规则**。政策覆盖上市房企再融资、并购重组、公司债、CMBS、[[02-45_公募REITs]] 等，本质是为行业下一阶段建立生存规则，而非给旧模式续命。
   - 旧模式（高杠杆 / 高周转 / 高扩张）成立前提是需求增长、房价单边涨、融资扩容；2020 年后收紧相当于"全行业压力测试"，正反馈逆转为负反馈。
   - 当前重开融资渠道，标志从"止血"进入"造血"，但**绝非回到银行贷款 + 居民预付款的老路**，而是建"投资 → 开发 → 运营 → 现金流 → 证券化"的可持续循环。
   - **融资逻辑从"看房企主体信用"转向"看项目本身价值"**——评判核心是项目有无真实需求、成本是否合理、能否产生稳定现金流；这是对"大而不能倒"的纠正。见 [[房企融资]]。
   - 国企可作风险处置的稳定器，**但绝不能成为房地产的永久接盘者**——仅更换所有者不改变资产价值，缺乏真实现金流的资产只是把风险从民营房企转移到地方国企与政府资产负债表。见 [[城投]]。
   - 终结的是依赖房价上涨、高杠杆、高周转与土地财政的**旧时代**；房企核心竞争力从融资 / 拿地转向产品 / 运营 / 持续现金流能力。

## 原文摘录

> 刘戈坦言，期房最大的吸引力当然是价格更低……但天下没有免费的午餐——买期房少花的那些钱，本质上就是一笔"风险费"。"一旦你撞上烂尾这个风险，那真的是非常痛苦。这不是概率游戏，而是 0 和 100% 的区别——要么没事，要么万劫不复。"

> 席迎春特别强调，国企可以作为风险处置的稳定器，但绝不能成为房地产的永久接盘者。仅更换资产所有者并不会改变资产本身的价值，缺乏真实现金流的资产，只是将风险从民营房企转移到地方国企与政府资产负债表，无法真正化解风险。

> 此次政策最核心的变化，是房地产融资逻辑从"看房企主体信用"转向"看项目本身价值"。未来金融机构与资本市场评判的核心，不再是企业规模、股东背景，而是项目有没有真实需求、成本是否合理、能不能产生稳定现金流。
