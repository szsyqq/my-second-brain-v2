

# 投资内容处理手册

> 本模块是「内容驱动」的投资决策系统。三层递进：**宏观定基调 → 行业选方向 → 个券落地**。核心是让每条进来的内容都逼出一个判断，并落到「利好 / 利空 + 估值锚点 + 如何驱动下一步投资」的框架里。

## 核心理念

信息持续流入（新闻、研报、个券报告、市场速览），决策离散发生（买 / 卖 / 加 / 减）。本手册只做一件事：**让每条进来的内容都逼出一个判断，并归集到「多空 + 估值锚点 + 下一步动作」的框架**——而不是堆成一座看了更焦虑的资料山。

## 关键更正：锚点 = 估值锚点（不是内容分类标签）

> ⚠️ **重点更正**：过去把内容分成「锚点 / 爆点 / 普通信息」是**错误的用法**。**「锚点」现在是每个行业、每个个券的「估值锚点」——判断它贵还是便宜的参考基准**，是一个挂在行业/个券上的**属性**，不再是给单条内容贴的标签。

- **锚点类型**（四选一或组合）：
  - **倍数中枢**：行业 / 个股历史或同业 PE / PB / PS / EV-EBITDA 中枢区间
  - **DCF 内在价值**：现金流折现测算的每股内在价值
  - **基本面驱动**：单位变量 → 利润弹性（如 $X/GW capex → 芯片需求 → 净利弹性）
  - **可比交易**：近期并购 / 定增 / 回购价
  1. **盈利预期修正**（上修 / 下修 → 锚点数值移动）
  2. **无风险利率 / 风险溢价变化**（→ 折现率 → 倍数与 DCF 同时移动）
  3. **行业格局 / 竞争结构变化**（→ 永续增速 / 毛利率假设）
  4. **同业重定价**（可比公司抬升 / 压缩估值带）
  5. **资本运作**（回购 / 分拆 / 并购 / 注资 → 每股价值重估）
- **用法**：处理任何一条内容时，先问——它是在**移动锚点**，还是只在**围绕锚点波动**？移动锚点 = 决策信号；围绕波动 = 等待催化 / 噪音。

## 三层体系

| 层 | 编号 | 回答的问题 | 枢纽 |
|------|------|------------|------|
| 宏观 | 02-10 | 现在是什么环境？风险偏好该高还是低？ | [[02-10_宏观]] |
| 行业 | 02-20~29 | 哪个赛道景气好、有催化、估值锚点有吸引力？ | [[02-20_行业]] |
| 个券 | 02-2X 下 | 具体哪个标的便宜 / 有催化剂、多空如何？ | 行业文件夹内 |

三层相互关联，更新时联动：宏观转向 → 重审行业估值锚点 → 调整个券仓位。

## 单条处理：四问（投资经理视角）

每进一条内容，先问自己这四问，再落笔：

1. **定性（多空 + 催化）**：偏 利好 / 利空 / 中性？催化性质是 突发 / 渐进 / 验证证伪？
   - 利好 = 提升标的 / 行业价值或概率的因素
   - 利空 = 压低的因素
   - 中性 = 补充事实但不直接改变多空（或纯噪音）
   - 注：原「锚点」作内容分类已废弃（见上）；原「爆点」保留为**催化性质**标记（突发冲击）
2. **信号判定**：能指导决策 / 噪音 / 过时？
   - **决策信号**：会改变持仓、观望或研究方向（尤其：**是否移动了估值锚点**）
   - **噪音**：有趣但无关决策
   - **过时**：已知信息重复，或已被市场定价
3. **机会**：带来什么投资机会？（方向 + 资产 + 逻辑链）没有就明写「暂无直接机会」
4. **观点对齐**：与主题已有观点 相同 / 相左 / 新维度？**相左的必须保留**——逼自己正视反面，而不是只收集印证自己的信息

## 个券档案：投资经理视角的八段结构

> ⚠️ **核心要求**：个券档案不是新闻复述，而是投资经理的尽调底稿。必须先讲清「这是家什么公司、处于什么位置」，再层层深入到逻辑、多空与决策。严格按以下八段组织（见 [[模板_个券档案]]）：

1. **公司概览**：主营业务一句话 + 行业地位（龙头/份额）。**业务占比细节不在这里写，放到第 2 节「业务构成」专门讲**。
2. **业务构成（独立小节）**：用表格讲清收入/利润由哪些板块构成、各自占比多少——这是判断「利润来源是否集中、风险在哪」的底数。
3. **关键财务指标**：表格三要素 = **现值 → 对比基准（同业/历史/一致预期）→ 为何看它（对决策的意义）**。删去「关键判断标准」这类不指向决策的字段。
4. **核心逻辑**（重点，不能简单），先写一句**总述**再展开：
   - **4.1 所属行业**：可跨多个行业，讲清各赛道钱从哪来、往哪走。
   - **4.2 投资逻辑主线**：一句话主线 + 展开（凭什么持续赚钱、为什么现在值得关注）。
   - **4.3 护城河**：专门讲护城河——每条是什么、当前是否稳固（A/B/C 分列，标 ✓稳固/○待观察/✗松动）。
   - **4.4 竞争与替代**：主要对手、是否有替代及进度、自身身位。
   - **4.5 关键关注 / 未来关注重点**：把「每条护城河是否稳定」转成**前瞻盯防清单**——列几个点，每个点写清「为什么盯、盯什么信号/阈值」。这是驱动下一步跟踪与决策的输入。
5. **估值锚点**：锚点类型 + 当前锚点值与安全边际 + 什么会移动锚点（五触发）。
6. **多空因素**：见下「多空因素表」。
7. **信息流（标准化表）**：见下「信息流表格化」。
8. **决策区**：见下「决策区的作用」。
9. **关联行业**：置底——放在「待探索」之后、全篇最后，向上链接所属行业档案。

## 档案总结：多空因素表（利好 / 利空）

> 这是本系统最核心的产出形态。每个行业、每个个券，都维护利好、利空两张表，而非散落的摘抄。**三列固定**：

| 列 | 内容 |
|----|------|
| 第一列：因素（A/B/C） | 一句话简述该利好/利空因素是什么 |
| 第二列：具体逻辑 & 来源 | 为什么成立、具体证据（数字/事件）+ `[[来源页]]` |
| 第三列：强化↑ / 消退↓ / 持平→ | 该因素**当前的趋势**——正在加强、减弱还是持平（取代旧的「是否已发生」标记） |

- **如何驱动下一步投资**（每篇档案的收口，可并入决策区或单列）：
  - **结论**：建仓 / 加仓 / 减仓 / 观望 / 等催化
  - **触发条件**：当 ___ 发生（锚点移动到 ___），执行 ___
  - **复盘点**：___

→ 多空表 + 估值锚点 + 下一步动作，三者齐备才算「消化完一条内容」。

## 信息流表格化

> 定性、催化性质、信号判定这些**判断本身是标准化字段**，应表格化沉淀，而非每条写成一段散文。

| 日期 | 信息内容（具体概括） | 定性 | 催化性质 | 信号判定 | 来源 |
|------|----------------------|------|----------|----------|------|
| … | 写清发生了什么（数字/事件），不要只写标签 | 利好/利空/中性 | 突发/渐进/验证证伪 | 决策信号/噪音/过时 | [[来源页]] |

- **关键**：第二列「信息内容」要**具体概括**——把事件、数字写出来，让人不点来源也知道发生了什么，而不是只留一个抽象标题。

## 决策区的作用

> 决策区 = **决策与问责台账**，与「信息流」严格区分：信息流记录**外部进来的信息与判断**；决策区只记录**我基于分析做出的实际动作**（建/加/减/观望）与事后复盘。

- 作用：检验判断对错、约束追涨杀跌、形成可回看的决策轨迹。
- 列：日期 / 决策（建·加·减·观望）/ 依据（触发条目）/ 状态 / 复盘结论。
- 若长期为空，说明尚无实际决策，可折叠——但保留其「问责」定位，不要用信息记录去填充它。

## 落到三层

1. 先判断这条内容属于哪一层（宏观 / 行业 / 某个券），以及它偏多还是偏空。
2. 处理完的条目，追加到对应档案的「信息流」。
3. 主题不存在 → 复制对应模板新建（行业用 [[模板_行业档案]]，个券用 [[模板_个券档案]]）。
4. 若条目触发了操作 → 在「决策区」记一行（决策 / 触发条目 / 状态 / 复盘点），并回流更新「多空因素」与「如何驱动下一步投资」。

## 宏观内容的处理（v7.5 新增）

> 宏观层「方法与状态严格分离」：**方法论进 [[02-10-00_宏观交易手册]]，时效性判断进 [[02-10_宏观]]**。

宏观素材走四问后，按内容性质分流：

1. **时效性观点/数据**（首席点评、周度跟踪、宏观数据解读）→ 落 [[02-10_宏观]] 信号流表，并回答宏观版信号判定：**它是否改变了 象限判定（regime）/ 周期定位 / 大类资产方向？**
   - 改变 → 属「观点变化」：更新枢纽 frontmatter（`regime` / `risk_appetite` / `asset_direction`）与「宏观立场速览」「大类资产方向」，**并触发宏观→行业反向联动**（对照「宏观→行业传导表」重审受影响行业页的 `stance`）
   - 不改变 → 信号流记一行，标「围绕现有判断波动」
2. **框架/方法论类**（首席分析框架、周期理论、交易框架、复盘范式）→ 落 [[02-10-00_宏观交易手册]] 对应框架节：
   - 是**新框架** → 新增一节（框架N），必须写成「输入指标 → 状态判定 → 资产动作」交易格式
   - 是**已有框架的参数修正/定位更新** → 在对应节内标注日期与来源修正（如郭磊周期定位年度更新）
3. **两者兼有**（常见：首席演讲既讲框架又给判断）→ 拆开各落各处，来源页同时被两页引用。
4. 传导判断落「宏观→行业传导表」（受益/受损行业 + 日期），并检查对应行业页是否需要联动。

## 市场速览（科技日报 / 周报）的处理

- 科技日报 / 周报 是美股科技、半导体、超大规模云厂 capex、内存周期与前沿模型的**每日 / 每周市场速览**，内含大量**个券报告、目标价、评级与多空判断**。
- 它们**已经可以、也应该被总结**：凡涉具体个券（如 META / NVDA / AVGO）的判断，走四问后**落到对应个券档案**；凡涉行业（如 AI 半导体、内存周期）的判断，落到对应行业档案。
- 来源页（如 [[2026-07-13-科技日报-0710]]、[[2026-07-13-科技周报-0713]]）作为「信息流」条目的来源链接保留，方便回溯原始底稿。

## 为什么这样设计

避免「信息越多越焦虑却不知道该做什么」：每条都逼出判断（多空 + 信号 + 机会 + 观点对齐），档案内自然沉淀出**多空对峙**与**估值锚点的移动轨迹**，并以「如何驱动下一步投资」收口——从宏观到个券的决策链条完整、可执行。
