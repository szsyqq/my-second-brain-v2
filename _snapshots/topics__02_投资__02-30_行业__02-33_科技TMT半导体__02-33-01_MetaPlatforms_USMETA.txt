

# Meta Platforms（USMETA）

> 全球社交广告双寡头之一，同时是算力扩张最激进的超大规模云厂：用广告现金流豪赌 AI（前沿模型 + API 商业化 + MTIA 自研硅）。

## 1. 公司概览

- **主营业务**：社交广告（Facebook / Instagram / WhatsApp）为核心现金牛；Reality Labs（元宇宙，长期投入亏损）；AI（前沿模型竞赛、模型 API 商业化、MTIA 自研 AI 芯片）。
- **行业地位**：全球数字广告双寡头之一（与 Google 并列），Family of Apps 月活约 30 亿+（约/待核实）；是 hyperscaler 中 capex 扩张最激进者之一。

## 2. 业务构成

> 收入高度集中于广告，本质是「广告现金流喂养 AI 重资本赌注」。

| 业务板块 | 收入占比 | 增长性 / 说明 |
|----------|----------|----------------|
| 广告（Family of Apps） | ~98% | 核心现金流，支撑全部 AI 投入 |
| Reality Labs（元宇宙/硬件） | ~2% | 持续亏损的长期期权 |
| AI / API 商业化 | 新兴 | 尚未规模化，Alexandr Wang 称将成「真生意」 |

> 占比约/待核实，需核对最新财报。

## 4. 核心逻辑

> **总述**：社交广告双寡头 + 最激进的算力豪赌者——用广告高毛利现金流换 AI 前沿模型与第一梯队身位；当前最核心的矛盾，是「capex 激进扩张的 ROIC 能否兑现」与「模型 / API 第二曲线能否打开」。

### 4.1 所属行业

数字广告 + AI 平台。广告是成熟高毛利现金流，AI 是用现金流换未来算力/模型主导权的重资本赌注；对 AI 半导体而言，Meta 的 capex 是需求锚上修的核心驱动。

### 4.2 投资逻辑主线

稳固的广告基本盘 + 激进算力投入 → 若前沿模型跻身第一梯队并把 API 做成生意，则打开广告之外的第二增长曲线；核心风险是 capex 的 ROIC 能否兑现。主线一句话：**广告现金牛喂养 AI 豪赌，赌的是模型/API 第二曲线能否兑现 ROIC**。

### 4.3 护城河

- A. **社交网络效应**（30 亿+ 用户的注意力池）→ ✓ 稳固
- B. **广告定向 + 数据闭环**（转化效率行业领先）→ ✓ 稳固（受隐私监管扰动）
- C. **算力 + 自研硅 → 模型竞争力**（MTIA + 14GW）→ ○ 待观察（第三名之争未定）

### 4.4 竞争与替代

- **主要对手**：广告端 **Google**、注意力端 **TikTok**；模型端 **OpenAI / xAI / Google**。
- **是否有替代 & 进度**：模型层竞争白热化，Muse Spark 1.1 / Grok 4.5 / GPT-5.6 齐发；SemiAnalysis 认为「第三名」之争在 **Meta vs SpaceX**（数据/人才/算力最均衡），而非 Google（[[科技日报-2026-07-10-META多方报告-STX升级-NVDA首选]]）。
- **自身身位**：广告基本盘领先；模型端并跑冲刺第一梯队。

### 4.5 关键关注 / 未来关注重点

- **关注点1：capex ROIC 能见度**。原因：$250B capex 远超 Street 预期，当日 META -4%；若财报未能把 capex 转化为广告/API 收入，估值锚下移、FCF 受压。盯财报 capex 转化与广告/API 收入。
- **关注点2：前沿模型第三名之争**。原因：SemiAnalysis 列 Meta 为「第三名」热门（与 SpaceX 而非 Google），Muse Spark 1.1 已发；若模型排名掉队，API 商业化期权贬值。盯模型基准与 API 收入。
- **关注点3：MTIA 自研硅量产（9 月）**。原因：博通设计+台积电制造，降外部依赖、保供毛利；若量产不及预期或性能不足，算力成本/供给承压。盯量产与性能对照。
- **关注点4：开源模型对模型层利润率的冲击**。原因：若开源压低模型利润率，基础设施投入回报再分配不确定，影响第二曲线估值。

## 5. 估值锚点

- **锚点类型**：倍数中枢（NTM PE）+ 基本面驱动（capex → 算力 → 模型竞争力 → 变现弹性）
- **当前锚点值 & 安全边际**：市场已计入近 $250B capex，估值锚受「capex ROIC 能见度低」压制折扣；安全边际待财报确认 capex 转化为广告/API 收入后重估
- **什么会移动锚点**：① capex 指引上/下修（盈利预期 + FCF）② 前沿模型排名（API 商业化进度）③ MTIA 量产（成本/供给）④ 利率 ⑤ 监管
