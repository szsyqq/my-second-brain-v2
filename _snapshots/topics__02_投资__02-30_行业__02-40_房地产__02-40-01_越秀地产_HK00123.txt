

# 越秀地产（HK00123）

> 广州国资委旗下红筹房企，1983 年成立、1992 年香港上市（00123.HK）。"商住并举 + 开发运营金融"，2025 年合约销售 1078 亿元（行业 TOP 9），总土储 2043 万㎡。

## 1. 公司概览

- **主营业务**：住宅及商业地产开发、物业租赁与运营、物业服务、房产基金（越秀房产基金）；"开发 + 运营 + 金融"模式。
- **行业地位**：中国房企综合实力第 6；中国第一代商品房缔造者、第一家地产红筹公司。

## 2. 业务构成

| 业务板块 | 说明 |
|----------|------|
| 住宅开发 | 合约销售主力（2025：1078 亿） |
| 商业地产开发与运营 | 写字楼 / 商场，与房托协同 |
| 物业服务（越秀服务） | 全国 10 强物服，提供稳定现金流 |
| 房产基金（越秀房产基金） | 全球唯一只投中国内地物业的港上市房托 |

## 4. 核心逻辑

### 4.1 所属行业

房地产（见 [[02-40_房地产]]）。行业处下行后政策托底期，国企相对民营有融资与信用优势。

### 4.2 投资逻辑主线

"地产国企化"样本：广州国资委信用 + 多元上市平台 + 房托 / 物服稳定现金流，在行业出清期相对占优；估值受 NAV 折价与破净压制。

### 4.3 护城河

- A. **国企信用与融资优势** → ✓ 稳固（相对民营）
- B. **房托 + 物服稳定现金流** → ✓ 稳固
- C. **土储质量与大湾区布局** → ○ 待观察（取决于去化）

### 4.4 竞争与替代

- **同业**：保利 / 华润 / 中海等央企，及民营出清后的份额转移；越秀以广州 + 大湾区为基本盘。

### 4.5 关键关注 / 未来关注重点

- **销售去化与回款**
- **行业政策**（减税 / 去库存 / 限购）
- **利率与融资环境**
- **房托分派与物服增长**

## 5. 估值锚点

- **锚点类型**：NAV 折价 / PB + 股息率
- **当前**：港股地产普遍深度破净，国企信用折价相对收窄
- **移动锚点**：销售修复、政策宽松、利率下行、土储去化
