

# 02-30 房地产

> 中国经济支柱行业，当前处下行后政策托底期。钱从"开发销售"转向"运营 + 金融（房托/物服）"，国企相对民营在信用与融资上占优。"地产国企化"是本轮出清的核心结构性变化。

---

## 0. 立场速览（≤5 行，打开页面 3 秒内看完）

- **立场**：低配（观望）＋ 行业仍处调整期，仅结构性机会（国企 / 房托 / 物服 / 项目层面现金流可验证的主体）
- **一句话逻辑**：政策从"托底"转向"重建规则"（现房销售 + 项目价值融资），但售价 / 去化 / 负债三压未解，估值深破净
- **当前最大矛盾**："止跌回稳"政策诉求 vs 居民杠杆与库存现实的拉锯；**外加上一层：出清的是房企而非房子**（[[2026-09-23-信评思维大发散]]）——供给未真正消失，不支持"供给出清→价格反弹"的简单类比

## 2. 周期坐标

- **生命周期**：成熟期（增量见顶，存量运营主导）
- **基本面周期（七阶段）**：下行 → 出清初（当前判断，依据：政策托底 + 核心区成交边际企稳，但库存与杠杆未解）
- **资本周期信号**：民营缩表 / 违约，国企与央企逆势拿地；REITs 扩容（华夏越秀高速 REIT、新世界上海 K11 C-REIT 等）提供退出与估值锚
- **改判条件**：70 城房价环比持续转正 + 库存去化周期回落 = 由出清初进入回升
- **2026-08 政策新增维度**：[[现房销售]]推进使"自有资金 + 融资能力"成为硬门槛，加速高杠杆企业出清；[[房企融资]]逻辑从主体信用转向项目价值，行业竞争要素从融资 / 拿地转向产品 / 运营 / 持续现金流

---

## 3. 供需与景气（量-价-库存）

- **需求端**：刚需 + 改善为主，投资性需求退潮；居民杠杆高、预期弱
- **供给端**：库存高位，新开工收缩；土地向国企/城投集中
- **库存与价格**：房价仍环比下行（多数城市），核心区与外围分化显著（见深圳案例）
- **景气度**：方向 ↓→企稳 ＋ 驱动变量：政策力度、收入预期、库存去化；拐点信号为房价环比转正

---

## 4. 产业链与利润池

- 链条：上游（土地/建材/金融）→ 中游（开发/施工）→ 下游（销售/物服/房托运营）
- **利润池迁移**：开发利润被压缩，利润向"运营 + 物服 + 房托管理费"迁移（轻资产、稳定现金流）
- **景气传导**：地产回暖 → 建材/家电/银行不良改善（领先/滞后关系：地产为早周期，但本轮传导钝化）

| 维度 | 内容 |
|------|------|
| 集中度 CRn | 国企/央企份额提升，民营出清（集中度上升） |
| 龙头与份额 | 保利/华润/中海/越秀等国企央企居前 |
| 进入壁垒 | 牌照（开发）+ 资金（融资）+ 政府信用（国企优势） |

---

## 5. 估值与拥挤度

- **估值锚点**：NAV 折价 / PB + 股息率；港股地产普遍深度破净
- **估值分位**：低（破净，处历史极低）
- **拥挤度**：低（机构低配，避险情绪）；落入四象限"观望格"

## 10. 债券视角（有存续债/城投产业债的行业启用）

- **行业利差**：地产债利差高位分化——国企/央企收窄，民营高收益债仍承压；关注中金/申万地产债利差
- **融资环境**：一级认购国企为主，民营净融资为负；到期压力集中于出清主体。**2026-08-28 新政后评判逻辑变化：从"看房企主体信用"转向"看项目本身价值"**——项目有无真实需求、成本是否合理、能否产生稳定现金流成为核心（见 [[房企融资]]）
- **尾部主体风险信号**：评级下调、展期/违约、销售回款恶化
- **行业准入策略**：景气下行 → 抬高准入，仅参与国企/央企与优质房托；**新增筛选条件**：优先考察项目层面现金流可验证、且有 CMBS/REITs 等现实退出路径的主体
