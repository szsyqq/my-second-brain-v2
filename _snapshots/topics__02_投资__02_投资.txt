

# 投资

> 投资决策系统。**宏观定并行策略 → 行业选方向 → 个券落地**。三层递进 + 并行策略矩阵，每层相互关联，更新时联动。

## 架构

```
02-10 宏观层（并行策略 S1~S5）→  定风险偏好、流动性、大类资产方向；多条策略并行执行（哑铃/事件驱动/全球配置/行业轮动/A股综合）
              ↓
02-20 行业                  →  选赛道、判景气、找催化；每个行业映射到适配策略
              ↓
02-2X/个券                  →  个券挂在所属行业文件夹下（标的名+代码），估值/信息流/决策区
```

## 用法

1. 拿到一条内容 → 打开 [[02-00_投资内容处理手册]]，走四问
2. 判断属于哪一层（宏观策略 / 行业 / 某个券），归到对应位置
3. 个券归到其所属行业文件夹下；若该行业尚无文件夹，先建行业档案再放个券
4. 触发三层联动时同步更新上下游（宏观转向 → 重审策略 → 调整行业观点 → 影响个券仓位）
