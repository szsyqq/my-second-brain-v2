

# 标的名称（代码）

> 一句话定位：它是谁、在产业链的什么位置。

## 1. 公司概览

> 第一屏：这家公司是做什么的、处于什么位置。业务占比细节放到第 2 节「业务构成」专门讲。

- **主营业务**：一句话说清它靠什么赚钱。
- **行业地位**：龙头 / 挑战者 / 利基；全球或国内份额约 __%；一句话身位。

## 2. 业务构成

> 单独小节：讲清收入 / 利润由哪些板块构成、各自占比多少。这是投资经理判断「利润来源是否集中、风险在哪」的底数。

| 业务板块 | 收入占比 | 增长性 / 说明 |
|----------|----------|----------------|
| A |  ~% |  |
| B |  ~% |  |

> 占比等数据若取自公开常识而非本库来源，标注「(约/待核实)」，不要把估算当作精确源数据。

## 3. 关键财务指标

> 只保留能驱动决策的指标。每个指标写清「现值 → 对比基准 → 为何看它」。删去「关键判断标准」这类不指向决策的字段。

| 指标 | 现值 | 对比基准（同业 / 历史 / 一致预期） | 为何看它（对决策的意义） |

| 盈利质量（如毛利率 / ROIC） |  |  |  |

## 4. 核心逻辑

> **总述**：一句话概括「它在什么赛道、凭什么值钱、当前最核心的矛盾是什么」。先给结论，下面再展开。

### 4.1 所属行业

> 可跨多个行业。讲清各条赛道钱从哪来、往哪走，以及本标的身处哪一段。

### 4.2 投资逻辑主线

> 一句话主线 + 展开：它凭什么持续赚钱 / 成长，为什么现在值得关注。

### 4.3 护城河

> 专门讲护城河——每条是什么、当前是否稳固。

- A. ___（是什么）→ 现状：✓ 稳固 / ○ 待观察 / ✗ 松动（一句话证据）
- B. ___（是什么）→ 现状：___
- C. ___（是什么）→ 现状：___

### 4.4 竞争与替代

- **主要对手**：X / Y / Z（各自身位）
- **是否有替代 & 进度**：___（技术 / 成本 / 生态角度，目前处于什么阶段）
- **自身身位**：领先 __ / 并跑 / 落后 __

### 4.5 关键关注 / 未来关注重点

> 把「每条护城河是否稳定」转成**前瞻盯防清单**：列几个点，每个点写清「为什么盯、盯什么信号 / 阈值」。这是驱动下一步跟踪与决策的输入。

- **关注点1**：原因（具体信号 / 阈值）—— ___
- **关注点2**：原因（具体信号 / 阈值）—— ___
- **关注点3**：原因（具体信号 / 阈值）—— ___

### 4.6 边际变化跟踪（投资经理视角）

> 投资经理最关心的是**变好还是变坏**，而非静态绝对值。本节记录个券层面关键经营/市场指标的边际变化方向，每期追加一行。

| 跟踪日期 | 收入/增速 | 毛利率/盈利 | 订单/出货 | 估值位置 | 多空净变化（↑N↓N→N） | 综合判定 | 备注 |
|----------|----------|-----------|----------|----------|---------------------|---------|------|
| YYYY-MM-DD | ↑/→/↓ | ↑/→/↓ | ↑/→/↓ | ↑/→/↓ | ↑ / ↓ / → | 改善/持平/恶化 | 触发事件 |

> **溢出规则**：若个券的边际变化明显（如收入增速连续 2 期下滑），需写回父行业档案的「边际变化跟踪」节——行业层面的边际变化不能只依赖自上而下的宏观判断，自下而上的个券信号同样重要。

### 4.7 债券信用分析（涉及债券时启用）

> 当标的涉及债券项目（信用债/可转债/可交债等）时，在此位置**嵌入 `[[模板_债券信用分析]]` 的全套分析模块**（发行主体介绍 → 信用基本面分析 → 信用利差判断 → 跟踪清单）。
>
> 嵌入方式：复制模板内容到此处，或用 wikilink 指向单独的子文件 `02-2X-NN_标的_信用分析.md`（推荐后者，保持个券主文件干净）。

## 5. 估值锚点

- **锚点类型**：倍数中枢 / DCF 内在价值 / 基本面驱动（单位变量→利润弹性）/ 可比交易
- **当前锚点值 & 安全边际**：现价 vs 锚点 = 折价 / 溢价 __%
- **什么会移动锚点**：① 盈利预期修正 ② 无风险利率 / 风险溢价 ③ 行业格局 / 竞争结构 ④ 同业重定价 ⑤ 资本运作（回购 / 分拆 / 并购 / 注资）
