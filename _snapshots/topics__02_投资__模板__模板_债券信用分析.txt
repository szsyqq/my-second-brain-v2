

# 模板：债券信用分析模块

> 当个券涉及债券项目（信用债/城投/金融债/可转债等）时，在标准个券八段结构的基础上，**嵌入**本模块作为第 X 节（建议跟在「多空因素」之后、「信息流」之前，在可转债情况下也可作为估值锚点的补充）。

---

## [N]. 债券信用分析

> ⚠️ **分清两个视角**：本节分析的是**发行主体**的信用质量，不是债券条款本身（条款在本节末尾单独说明）。评级人员关心「能不能还」，投资经理在此基础上额外关心「价格是否反映了风险」。

### N.1 发行主体介绍

| 字段 | 内容 |
|------|------|
| **公司名称** | 全称 + 简称 |
| **行业** | 所属申万行业/中债行业分类 |
| **商业模式** | 一句话：怎么赚钱（B2B/B2C/政府）、收入驱动力、成本结构中最大项 |
| **行业地位** | 市场份额排名、是否是龙头/区域主力、有无定价权 |
| **主要风险点** | 列举 3-5 个最关键的风险（经营/财务/行业/治理/政策），每条一句话 |

**参考维度**：若已有「公司概览」和「业务构成」节，此处可直接引用 + 补充信用视角特有的点（如对银行信贷依赖度、应收对象集中度、关联方占款等）。

### N.2 信用基本面分析

#### N.2.1 企业经营情况

> 不只是「收入增速多少」，要回答：**收入的质量和可持续性如何**。

- **收入质量**：现金收入比（经营现金流入 / 营业收入）——越高越好，常年低于 0.8 需警惕
- **客户集中度**：前 5 大客户占比；单一客户依赖 > 30% 为预警
- **供应商集中度**：同上；集中度高 = 议价权弱 + 断供风险
- **业务稳定性**：收入是否受周期性/季节性冲击、是否有长期合同/经常性收入
- **应收账款周转**：账龄结构、回款周期、坏账计提是否充分

#### N.2.2 财务情况

| 指标 | 现值 | 同比变动 | 行业均值 | 信号判定 |
|------|------|----------|----------|----------|
| 总资产 | | | | 扩张方向（过快=风险or成长） |
| 资产负债率 | | | | 杠杆高低 |
| 有息负债率 | | | | 显性杠杆 |
| 短期债务/总债务 | | | | 短期偿付压力 |
| 净资产 | | | | 安全垫厚度 |

> **关键逻辑链**：负债率高 ≠ 一定差——要看行业特征（公用事业/基建天然高杠杆）。重点是比较**同行业同规模**的负债结构与变化趋势。

#### N.2.3 现金流情况

> 利润是纸面、现金流是现实。**经营现金流是偿债的第一来源。**

- **经营现金流 / 营业收入**：≥10% 为及格线，低于说明盈利变现能力差
- **自由现金流（FCF）**：经营现金流 - 资本开支。持续为负 = 需外部融资补，债务依赖上升
- **FCF / 总债务**：衡量「用内生现金流还债」的能力。≥5% 及格
- **经营现金流 / 利息支出（现金利息覆盖倍数）**：≥2 倍为安全
- **融资现金流**：近 3 年筹资行为——借新还旧还是融资扩张？

#### N.2.4 偿债能力

| 指标 | 现值 | 阈值参考 | 说明 |
|------|------|----------|------|
| 流动比率 | | ≥1.5（制造业）；≥1.0（公用） | 短期流动性 |
| 速动比率 | | ≥1.0（制造业）；≥0.5（公用） | 剔存货后短期流动性 |
| EBITDA / 利息支出 | | ≥3 及格；≥5 良好 | 息税前利润覆盖利息能力 |
| 经营现金流 / 短期债务 | | ≥0.3 及格 | 现金偿还短期债务能力 |
| 货币资金 / 短期债务 | | ≥0.5 安全；<0.3 预警 | 即时偿付能力 |
| 未使用授信额度 | | 越大越安全 | 备用流动性 |

#### N.2.5 行业周期

1. **行业处于什么周期阶段**？——上升/顶峰/下行/谷底
2. **当前位置在周期中的位置**？——早期/中段/尾部
3. **周期对行业内企业的差异化影响**？——龙头抗周期能力更强，尾部企业下行期违约风险骤升
4. **当前政策环境**？——监管放松/收紧、环保限产、产能审批政策方向
5. **行业盈利中枢趋势**？——毛利率趋势性上升/下降/波动；ROE 趋势

### N.3 评级人员视角 vs 投资经理视角

#### 如果我评级，我关注什么？

1. **经营层面**：业务可持续性——商业模式是否脆弱？客户/供应商集中度？政策风险？
2. **财务层面**：负债率是否可持续 → 有息负债率趋势、短债占比、是否存在隐性负债
3. **现金流**：经营现金流是否覆盖利息和短债本金
4. **偿债意愿**：有无违约史、大股东是否侵占上市公司现金流、外部审计意见
5. **外部支持**：股东背景、政府支持力度、银行授信合作稳定性
6. **行业风险**：行业景气下行期公司的财务弹性空间

> 评级视角的核心公式：**信用质量 = (经营稳健性 + 现金流创造能力 + 外部支持) ÷ (负债率 + 短债占比 + 或有负债)**

#### 如果我做投资经理，我额外关注什么？

1. **信用利差是否合理** → 理论利差 vs 市场定价的差异在哪？
2. **利差的边际变化方向** → 走扩是因为信用恶化还是流动性冲击？
3. **久期与杠杆策略** → 短债防御 vs 长债超额收益
4. **流动性风险** → 市场差的时候卖得掉吗？
5. **相对价值** → 同业同期限同评级比较
6. **条款保护** → 交叉违约/担保/抵押/回售
7. **催化剂跟踪** → 评级调整/行业政策/再融资可能性
8. **组合集中度风险** → 单券占比、行业暴露

### N.4 信用利差判断

#### N.4.1 基准参考

| 项目 | 参考值 | 说明 |
|------|--------|------|
| 同期限国开债收益率 | ___% | 无风险基准 |
| 同评级行业中位数利差 | ___BP | 行业基准 |
| 同评级同业可比利差 | ___BP | 可选 2-3 家可比公司 |
| 该公司存量债券利差 | ___BP | 如有存量券，以最新成交/估值 |

#### N.4.2 利差加减项分析

| 调整维度 | 方向 (+BP / -BP) | 依据 |
|----------|------------------|------|
| 规模溢价/折价 | | 龙头享流动性溢价；小规模/低流动加项 |
| 股东背景 | | 央企/国企/民企信用谱系不同 |
| 财务健康度 | | 杠杆率偏离行业中位数 |
| 经营稳定性 | | 收入波动率、客户集中度 |
| 外部支持 | | 政府支持/银行授信/母公司信用延伸 |
| 流动性 | | 债券存量规模、换手率 |
| 条款保护 | | 交叉违约/担保/抵押/回售 |
| 或有风险 | | 担保余额/诉讼/潜在处罚 |

#### N.4.3 理论利差区间

| 情景 | 利差 (BP) | 概率权重 | 说明 |
|------|-----------|----------|------|
| 基准情景 | BP | ___% | 按当前经营+财务现状外推 |
| 上行情景 | BP | ___% | 经营改善/行业上行/评级上调 |
| 下行情景 | BP | ___% | 经营恶化/行业下行/评级下调 |

**预期利差 = 基准 × P(基准) + 上行 × P(上行) + 下行 × P(下行) = ___ BP**

> ⚠️ **三情景概率之和须为 100%**。

#### N.4.4 结论

- 当前市场定价利差：___ BP
- 理论合理利差：___ BP
- **判断**：偏贵 / 合理 / 偏便宜
- 信号：买入 / 持有 / 卖出 / 等待
