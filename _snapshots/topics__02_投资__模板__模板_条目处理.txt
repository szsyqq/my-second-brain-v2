

# 模板：单条内容处理（条目）

> 每进一条新闻 / 研报 / 个券报告 / 市场速览，先按下面四问过一遍，再追加到对应主题档案的「信息流」。来源可以是素材页、实体页、或外部链接。

```markdown
### [事件日期] 标题（来源：[[素材/实体]]）

- **定性**：利好 / 利空 / 中性
  - 利好 = 提升标的/行业价值或概率的因素
  - 利空 = 压低的因素
  - 中性 = 补充事实但不直接改变多空（或纯噪音）
- **催化性质**：突发（一次性冲击）/ 渐进（缓慢演进）/ 验证证伪（印证或推翻已有判断）
  - 注：原「锚点」不再是内容分类标签；锚点现在是每个行业/个券的**估值锚点**属性（见档案）。本字段只标记这条信息"像不像催化剂、是突发还是渐进"。
- **信号判定**：决策信号 / 噪音 / 过时
- **机会**：方向 + 资产 + 逻辑链（无则明写"暂无直接机会"）
- **观点对齐**：相同 / 相左 / 新维度
  - ⚠️ 相左必须保留——逼自己正视反面，而不是只收集印证自己的信息
- **我的处理**：一句话结论 + 它**是否移动了估值锚点** + 是否需要行动（建仓 / 加仓 / 减仓 / 观望 / 等催化 / 忽略）
- **关联**：[[主题档案]] [[相关素材/实体]]
```
