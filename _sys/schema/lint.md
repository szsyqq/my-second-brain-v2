# Lint — 健康检查规则

> `.wiki-schema/modules/lint.md` | 版本 3.0

## 检查范围

随机抽查 10 个页面 + 最近更新 10 个页面

## 检查项

| 项目 | 说明 |
|------|------|
| 页面间矛盾 | 不同页面对同一事实的说法是否冲突 |
| 孤立页面 | 是否有页面未被任何其他页面链接 |
| 断链 | `[[链接]]` 指向的文件是否存在 |
| 交叉引用缺失 | 相关主题是否应该互链但没链 |
| index 一致性 | index.md 条目与实际文件是否匹配 |
| inbox 堆积 | `raw/inbox/` 是否有未处理文件 |

## 输出

中文报告，每个问题附修复建议。
