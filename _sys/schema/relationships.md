# 关系类型词汇表

> `.wiki-schema/modules/relationships.md` | 版本 3.0

用于 Mermaid 知识图谱中的关系标注。

| 类型 | 含义 | Mermaid |
|------|------|---------|
| 实现 | A 是 B 的具体实现 | `A -->\|实现\| B` |
| 依赖 | A 依赖 B 才能工作 | `A -->\|依赖\| B` |
| 对比 | A 与 B 是同类可比较 | `A -->\|对比\| B` |
| 矛盾 | A 与 B 存在观点冲突 | `A -->\|矛盾\| B` |
| 衍生 | A 从 B 演化而来 | `A -->\|衍生\| B` |
