> `.wiki-schema/modules/travel.md` | 领域模块 | 版本 3.0

旅游内容的总结必须围绕"一个旅行者真正需要知道什么"来组织，不能套用通用知识分类框架。

## 目的地级页面结构

每个目的地页面必须包含以下维度，不可缺省：

```markdown
---
tags: [旅游, {目的地}]
created: YYYY-MM-DD
updated: YYYY-MM-DD
sources: [所有关联素材列表]
---

# {目的地}旅游

> 一句话定义：核心吸引力 + 适合人群

## 概览
- **最佳季节**：具体月份 + 理由
- **建议天数**：最少 / 推荐
- **预算等级**：穷游 / 舒适 / 奢华 大致区间
- **适合人群**

## 景点
按「必去 / 推荐 / 可跳过」三级分类，每个景点：
- 名称 + 亮点
- 门票 / 预约（是否需要、在哪约、价格、提前多久）
- 交通到达
- 建议游玩时长
- 开放时间 / 闭馆日

## 美食
- **推荐菜品**：菜名 + 在哪吃 + 大致价格
- **推荐餐厅 / 区域**：名称 + 位置 + 人均
- **特色体验**：市场、小吃街、咖啡馆

## 交通
- **到达方式**：机场 / 火车站 → 市区
- **市内交通**：地铁 / 公交 / 租车 / 骑行 优劣对比
- **通票 / Pass**：有没有、值不值
- **实操 Tips**：素材中的具体经验

## 住宿
- **推荐区域**：住哪个区最方便
- **推荐类型**：酒店 / 民宿 / 青旅
- **具体推荐**：有素材支撑的酒店名 + 体验

## 购物
> 目的地有购物相关内容时增加此节

- **推荐商品 / 店铺 / 价格**

## 行程推荐
> 基于已有素材的行程框架，未覆盖标注 "(待补充)"

| 天数 | 行程 | 交通 | 住宿 |
|------|------|------|------|

## 注意事项
> 按重要性排序，每条来自具体素材

### 预约相关
- 景点 / 活动预约要求、提前时间

### 出行细节
- 支付、网络、语言、安全

### 季节 / 天气
- 各季节注意事项

### 避坑指南
- 素材中的踩坑经验
```

## 写作规则

1. **观点必须具体**：含价格数字、时间、地点、步骤，禁止"XX 很好"这类空洞表述
2. **标注来源**：每个事实标出来自哪篇素材（`[[来源摘要页]]`）
3. **禁止"待办事项"**：知识库不是任务管理工具
4. **"未解决的问题" → "待探索"**：积极的素材收集方向
5. **Wikilinks 用实际文件名**：`[[03-01_日本旅游]]` 而非 `[[日本旅游]]`
6. **空缺诚实标注**：无素材的维度标注 "(暂无素材)" 或 "(待补充)"，不做猜测
