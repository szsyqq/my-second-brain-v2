# 指标刷新台账

> `/gx` 流程「指标刷新」步骤的操作依据。每次 /gx 按本表遍历，用财汇/同花顺 MCP 更新可量化指标的最新值，与上期对比判定趋势；拿不到的指标冻结标记「不可得」，不再反复空跑。
>
> 数据源工具名（财汇 `caihui_mcp` 二级工具、同花顺 `hexin-ifind-ds-edb-mcp` 的 `get_edb_data`）以执行时 ToolSearch 加载的实际工具为准，本表只标「数据源优先级 + 查什么」。

## 取数优先级（固定，逐级降级，不可跳过）

1. **财汇 MCP**（`caihui_mcp`，先 `caihui_mcp_metadata` 定位子工具再 `execute_tool`）：利率/利差、行情估值、宏观区域经济
2. **同花顺 iFind MCP**（`hexin-ifind-ds-edb-mcp` 的 `get_edb_data`）：宏观/行业经济指标，自然语言查询
3. **网络搜索**（WebSearch）：前两者拿不到时兜底
4. **冻结**：以上均拿不到 → 状态标「不可得」，记入「已知冻结项」，之后不再主动重试（除非用户点名该指标）

### 并发限流处置（2026-10-16 补）

同花顺 `get_edb_data` 单轮并发调用会触发 `429 请求过于频繁`。**一次只发 1–2 条**，串行推进；被 429 挡下的查询在下一轮单独重发即可成功，不必换查询词。

### 术语命中经验（直接抄用，省一轮试错）

| 目标 | 有效查询串 |
|------|-----------|
| 制造业 PMI | `制造业PMI 建筑业PMI 当月值 2026年X月`（**只回制造业**，建筑业需单独查） |
| 建筑业 PMI | `建筑业PMI 商务活动指数 月度 2026年`（勿加「非制造业」，会返空） |
| 工业企业利润 | `工业企业利润总额累计同比 月度 最新值 2026年`（一次回累计值/累计同比/当月同比三列） |
| CPI+PPI | `CPI当月同比 PPI当月同比 月度 最新值 2026年` |
| DR007 | `存款类机构质押式回购加权利率 7天 DR007 日度…`（**必须带「存款类机构」**，否则回 R007） |
| 政策利率 | `7天期逆回购操作利率 央行 公开市场操作 最新值 2026年` |
| 信用利差成分 | `中债中短期票据到期收益率 AAA 5年 日度…` + `中债国债到期收益率 5年 日度…` 两查相减 |
| 指数收盘/月收益基准 | `AAA指数名 收盘价 日频 2026-09-10至2026-10-15`（一次只回一个指数，需分查） |

## 趋势判定规则

- **方向**：对比「最新值」与「上期值」→ ↑ 升 / ↓ 降 / → 持平（幅度小于波动阈值视为持平）
- **趋势性调整** = 连续两期同向，或突破关键阈值（荣枯线 50、利差 0、PE 历史中枢 ~13 倍等）→ 写入更新记录「观点变化」节，并回写对应策略页/仪表盘「最新值/判定」列
- **方向含义**：不同指标 ↑ 的利多/利空方向不同，见各表「方向含义」列

## 状态取值

| 状态 | 含义 |
|------|------|
| 可获取 | 数据源已打通，每次 /gx 正常刷新 |
| 待验证 | 尚未成功取数过，下次 /gx 首次尝试 |
| 不可得 | 财汇+同花顺+网络搜索均拿不到，已冻结，不再主动重试 |
